Praticar os principais seletores CSS resolvendo desafios no jogo.

Resposta correta: +10 pontos. Resposta incorreta: -5 pontos.

Após abrir uma fase, para voltar à página inicial é necessário clicar no botão vermelho de parar do Scratch.
